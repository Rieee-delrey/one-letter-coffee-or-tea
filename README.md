One letter, A for coffee. The first letter of the alphabet staking the first drink of the day — coffee's own boldness, landing as the opening shot in the coffee against tea argument. The program writes exactly one byte, `A`, to `/output/entry.txt`, checks it is a single non-space character first, and verifies the output byte-for-byte afterwards.

## Run it

```sh
python3 main.py
```
